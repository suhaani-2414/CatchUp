# CatchUp 📚

CatchUp is a student-first web application built for UMBC students to quickly catch up on what they missed in class through anonymous peer updates.

## 🚀 Features
- Search for classes by university and course code
- View real-time, anonymous class updates
- Post updates with topics like attendance, exams, homework, and lecture summaries
- Rate importance of lectures
- Like, share, edit, and delete your own updates
- Clean, modern UI focused on usability

## 🛠 Tech Stack
- HTML
- CSS
- Vanilla JavaScript
- Firebase (database)
- Netlify (deployment)

## 🌐 Live Demo
👉 https://catchup-st.netlify.app

## 📌 Motivation
Built to solve a real student problem — missing a lecture shouldn’t mean falling behind.

## 🎓 Current Scope
CatchUp is currently designed for University of Maryland, Baltimore County (UMBC) students.  
The project structure allows for easy expansion to other universities in the future.
